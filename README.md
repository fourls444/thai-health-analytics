# Thai Health Analytics

โปรเจกต์วิเคราะห์ข้อมูลสุขภาพที่พัฒนาต่อจากงานในวิชา Big Data Analytics ใช้ Python และ pandas เตรียมข้อมูล แสดง dashboard ผ่าน Streamlit ด้วยกราฟ Vega-Lite ที่ปรับตามหน้าจอ ส่วน notebook ใช้ Matplotlib และ Seaborn

## ทำอะไรได้บ้าง

- เปรียบเทียบจำนวนและอัตราผู้ป่วยความดันโลหิตสูงรายจังหวัด ปี 2559–2561
- ดูแนวโน้มรายจังหวัดและเปรียบเทียบเขตบริการสุขภาพ
- ดูจำนวนการวินิจฉัยรายวันในปี 2016 แยกตามหมวดรหัส
- ตรวจค่าว่าง แถวซ้ำ และชนิดข้อมูล พร้อมดาวน์โหลด CSV
- อ่านสรุปข้อความและเปิดตารางข้อมูลของแต่ละกราฟได้
- สร้างกราฟเฉพาะแท็บที่เปิดอยู่ พร้อม skeleton ระหว่างเตรียมข้อมูล

อ่านขั้นตอนวิเคราะห์ใน `notebooks/01_exploratory_analysis.ipynb` ส่วน `src/` เก็บฟังก์ชันอ่านข้อมูล คำนวณ สร้างกราฟ และตรวจคุณภาพข้อมูล

## เปิดใช้งาน

ใช้ Streamlit ตั้งแต่เวอร์ชัน 1.64 เพื่อให้แท็บสร้างเนื้อหาเฉพาะส่วนที่เปิดอยู่ หากมี `.venv` แล้ว ให้ติดตั้งจาก `requirements.txt` อีกครั้งเพื่ออัปเดตแพ็กเกจ โดยไม่ต้องสร้าง `.venv` ใหม่

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันบน Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

เลือกตัวกรองปีและเขตจากแถบด้านข้าง หากต้องการเปิด notebook หรือรันชุดทดสอบ ให้ติดตั้งแพ็กเกจสำหรับพัฒนาเพิ่ม:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

เปิด notebook ได้ด้วย `.\.venv\Scripts\python.exe -m jupyter notebook` ส่วนการ deploy dashboard ใช้เฉพาะ `requirements.txt`

## ข้อมูลและเครดิต

โปรแกรมต้องใช้ไฟล์ต่อไปนี้ใน `data/raw/`:

- `hypertension_all.csv`: จำนวนผู้ป่วยรายจังหวัด ปี 2559–2561 และประชากรกลางปี
- `diag_code_2016.csv`: จำนวนการวินิจฉัยรายวัน ปี 2016 แยกตามหมวดรหัส

ข้อมูลทั้งสองชุดใช้ประกอบการเรียน โดยขอขอบคุณและให้เครดิต [melivecode](https://melivecode.com/) สำหรับข้อมูลและสื่อการสอนที่ใช้เป็นพื้นฐานของโปรเจกต์ ไฟล์ CSV รวมอยู่ใน repo เพื่อให้เปิดตัวอย่างนี้ได้ ข้อมูลไม่ใช่ผลงานที่ผู้พัฒนาเก็บรวบรวมเอง

ฟอนต์ Noto Sans Thai รวมอยู่ใน `assets/fonts/` พร้อมใบอนุญาต SIL Open Font License 1.1 ใน `OFL.txt` ใช้ไฟล์เดียวกันทั้งหน้าเว็บและกราฟใน notebook โดยไม่ดาวน์โหลดฟอนต์ระหว่างเปิดแอป

อ่านสื่อการสอนที่เกี่ยวข้องได้ใน [Data Visualization with Power BI ของ melivecode](https://www.melivecode.com/pdf/powerbi.pdf) เครดิตข้อมูลแยกจากผลงานพัฒนาโค้ดและ dashboard และไม่ได้หมายความว่า melivecode รับรองผลวิเคราะห์นี้ หากนำข้อมูลไปใช้ต่อ ให้ตรวจสอบเงื่อนไขกับผู้เผยแพร่ข้อมูล ไม่ถือว่าใบอนุญาตของโค้ดครอบคลุม CSV โดยอัตโนมัติ

## ข้อจำกัด

- ใช้ประชากรกลางปีคอลัมน์เดียวคำนวณอัตราของทั้งสามปี ไม่ใช่ประชากรแยกตามปี
- หน้า Data Quality ตรวจข้อมูลหลังเตรียมแล้ว จึงไม่ใช่รายงานปัญหาทั้งหมดในข้อมูลดิบ
- กราฟเปรียบเทียบเขตแสดงทุกเขต แม้จะเลือกกรองเขตในส่วนอื่น
- ผลวิเคราะห์ใช้เพื่อการศึกษา ไม่ใช้สรุปสาเหตุของโรคหรือประกอบการตัดสินใจทางการแพทย์
