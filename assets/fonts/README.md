# Noto Sans Thai

`NotoSansThai.ttf` is the unmodified variable font downloaded from the Google Fonts repository:

- Source: https://github.com/google/fonts/tree/main/ofl/notosansthai
- Original filename: `NotoSansThai[wdth,wght].ttf`
- Copyright: The Noto Project Authors
- License: SIL Open Font License 1.1, included in `OFL.txt`.

The dashboard embeds this local file in its stylesheet. Notebook charts register the same font with Matplotlib. No font download is required when the app runs.
